# 게임시트 (게임 데이터 표에서 뽑은 자료)

`도구\game_sheets.py`(빌드PC)가 게임 설치본의 데이터 표(`data\game\*.dl_bin`)와 공식 문자열에서 만듭니다. 손으로 고치지 않습니다.
위키 같은 외부 자료는 넣지 않습니다. 위키 값은 아래 '확인' 칸에서 칸 뜻을 맞춰 보는 데만 썼습니다.

## 갱신 (빌드PC, 게임 업데이트 뒤)

1. `PYTHONPATH=소스\pylib py -3.14 -X utf8 도구\game_names.py` (공식 번역표를 게임 빌드에 맞춰 다시 뽑음)
2. `PYTHONPATH=소스\pylib py -3.14 -X utf8 도구\game_sheets.py`
3. commit, push. 분석PC, 팬 사이트(`superguide-v2`)는 이 폴더를 읽음

찾기: `python -X utf8 도구\term.py <이름, 코드, 경로 일부>` (게임 없는 PC 에서도 됨)

## 칸 뜻과 근거

칸 자리는 게임 형식 정의 `data\game\dl_library.dl_typelib`(암호화, dl_bin 과 같은 열쇠. 형식 이름은 해시, 칸 이름은 지워져 있음)의 64 비트 자리로, 칸 이름은 filediver datalibrary(BSD-3) 구조체의 칸 순서로 맞췄습니다.
엔티티 변형(같은 무기의 다른 판, 적 변종)은 `generated_entity_deltas.dl_bin` 의 변경분을, 무기는 기본 부착물(`generated_weapon_customization_settings`)의 변경분을 덧씌운 값입니다.

## 아직 미확인이거나 빠진 칸 (쓰기 전에 확인)

- 무기: 재장전 시간은 `재장전_시간`(+56) 이 0 인 무기가 많음(애니메이션 기본 길이, 데이터 표 밖)
- 분사 무기 화면(2026-11-25 상점 '자유의 불꽃' 아이템 정보): 토처 용량 100, 반동 001, 크리스퍼 용량 050, 반동 002 = 시트 `탄창`, `조작.화면.목록_반동`(0.75, 1.5 반올림)과 같음. 두 무기 모두 '초당 대미지 380' 은 시트 칸(분사 피해 2)만으로 계산되지 않음(분사 빈도 칸 미확인)
- 분사 무기(`분사`): 피해 종류 +200 은 위키 datamine 분사 피해와 같음(토처 2, 크리메이터 3, 스테릴라이저 1). `칸0_16`(+4 = 화염 10, 가스 15 등)과 분사 거리, 초당 분사 수는 칸 이름이 없어 뜻 확인 전. 크리메이터의 `연결_탄약_원값`(WeaponLinkedAmmo)도 뜻 확인 전, 예비 연료는 `배낭`(500)
- 2026-11-25 까지 빠졌던 무기와 이유: 화염방사 계열 5종과 파이로텍, 화염 센트리는 `SprayWeaponComponentData`(분사) 만 있어 무기 고르기(투사체, 빔, 아크)에 안 걸림. 탈론(LAS-58)은 백과사전의 보통 표기 이름(+0) 문자열이 번역표에 없어 이름이 빈 것으로 걸러짐 → 무기 코드가 있으면 대문자 표기(+8, 'TALON')로 대신함. 그래서 탈론의 `en` 은 'TALON'. `hd2_datatable.HEAT_KIND`('과열 표') 블록이 이 분사 표(typelib 이름 SprayWeaponComponentData)
- 적: 부위 이름은 filediver 해시 목록으로 풀린 것만 이름, 나머지는 16진
- 방어구: 장갑 등급, 속도, 기력 회복 수치는 데이터 표에 없음(무게 등급에서 게임 코드가 정하는 것으로 보임)
- **부스터, 작전 제한 조건, 함선 모듈, 임무 정의는 게임 파일에 없음**(2026-11-25): 이름 문자열 id 를 dl_bin 55개와 게임 리소스 약 4만 9천 개(텍스처, 소리 제외, `hd2_datatable.resources`)에서 찾았으나 0. 암호화된 game.dll 안으로 보임(`적_스폰표.json` 과 같은 사정). 이름과 설명 문장만 공식 문장표(`소스\용어\게임_명칭.json` 의 `공식_명칭`, `참고자료\공식번역`)에 있음. 함선 모듈 표처럼 보이는 `generated_stratagem_upgrade_settings` 는 항목 1개뿐이라 함선 모듈 표가 아님. SEAF 야포 5발처럼 엔티티 쪽 횟수도 못 찾음
- 상태 이상(`generated_status_effect_settings`), 작전 변수(`generated_modifier_settings` 15), 임무 시나리오(`generated_scenario_settings` 39)는 숫자만 있고 키가 해시 목록에 없어 이름과 짝을 못 지음. 뽑지 않음
